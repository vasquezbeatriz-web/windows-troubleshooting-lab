# Windows Troubleshooting Lab

## Sobre o projeto

Este projeto simula atividades de troubleshooting e suporte técnico
em ambientes Windows.

O objetivo é desenvolver habilidades práticas para atuação em
Service Desk, Suporte Técnico e Infraestrutura.

## Objetivos

- Diagnosticar problemas em Windows
- Utilizar ferramentas nativas de diagnóstico
- Desenvolver metodologia de troubleshooting
- Documentar incidentes
- Desenvolver raciocínio técnico para resolução de problemas

## Ferramentas utilizadas

- Windows
- Task Manager
- Event Viewer
- Resource Monitor
- Reliability Monitor
- Services
- Ferramentas de diagnóstico de rede

## Incidentes

| ID | Problema | Status |

## Competências desenvolvidas

- Windows troubleshooting
